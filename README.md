# STAT306-F26-live-coding
repository for STAT 306, Fall 2026 live coded data explorations

Assign yourself one Live Code issue and one Annotate issue by adding a comment to the relevant issue that tags your GitHub account (see [here](https://github.com/sastoudt/STAT306-F26-live-coding/issues/21) for an example).

The live code issue will be completed in class on the date, the annotation must be completed no later than two days after the date the live coding happens on.
